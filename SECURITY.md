# Security policy

Do not open a public issue for a suspected vulnerability, exposed credential, or customer-data concern.

Report security issues to [support@tenqual.com](mailto:support@tenqual.com) with the subject `Security report`. Include the affected workflow, reproduction steps, and impact, but do not include live credentials or unnecessary customer data.

Tenqual will acknowledge reports as soon as practical, investigate them, and coordinate remediation and disclosure where appropriate.
